To start, a basic class system and main file was implemented to start simulating how the UI will work for the clinic's patients trying to either book an appointment or check their existing ones, with some basic information the patient can input. This is currently being simulated in the console until we finish a UI framework. The doctor side of this has been left-out for the initial prototypes. This will help as we begin formulating the rest of the project, as the core of the project is appointment management, so we're starting at the core of it and then trying to branch out from there. 

We have also begun to use some interaction between different files, through our files interacting with each other, currently we're loading test variables from the files themselves, but this connection will be good for when we get a database system working, for actual variable storage and data reading, which will be important for actually storing patient's appointments, doctor's info, names, availabilities, and much more.

For the user interface, a separate branch with a JavaFX Maven build has been established for testing purposes, but no actual development there as its on a base template. This will be important as eventually we'll need a JavaFX framework, so we can display an actual user interface with enterable fields, as for a lot of patients a good UI will be far easier to navigate and more familiar then a console line app. The clinic will be serving a wide variety of people, so it's good to make a custom more streamlined design so both the doctors and the patients to have something easy to use. 

2. Class structure

Class: Patient
Attributes: id: String , name: String, number: String

Methods: 
getId() - Returns the value of the patient id
getName() - Returns the value of the patient name
getNum() - Returns the value of the patient number

Justification:
The patient themselves need to be modelled in the program.
The Patient class stores all of the information related to each unique patient including name, id, and number.

Class: Appointment
Attributes: doctorID: String, patientID: String, healthcardNum: String, time: integer

Methods: 
getdoctorID() - Returns the value of the appointments doctors id
getappointmentID() - Returns the value of the appointment id
gethealthcardNum() - Returns the vlaue of the appointments health card number
gettime() - Returns the appointment time

Justification:
The Appointment class models the appointments themselves by storing and associating the
patient healthcardNum, doctors doctorID, the appointments appointmentID and the time of the appointment. 

Class: Doctor
Attributes: doctorID: String, name: String, timeslots: Appointment[]

Methods:
getdoctorID() - Returns the value of the doctors id
getname() - Returns the value of the doctors name
displayschedule() - Displays the status of the doctors 30 min schedule slots

Justification:
The doctors each have their own unique variable values so they must each be their own objects.
Since each doctor has their own schedule each doctor object contians their array to store their appointments.

Class: Booking
Attributes:check: int, doctors: Doctor[]

Methods:
makeDocs() - Creates a few pre determined doctor objects for testing
WelcomeMSG() - Displays a welcome message as well as options to continue
appointmentnew(Doctor doc, Patient pat, String appid, String time) - 
patientnew(String id, String name, String number) - Creates a new patient object
chooseDoc() - Displays the list of available doctors as options to choose
booktime(int timeindex, Appointment name, Doctor doc) - Books appointment at determined time if available
checkapps(Doctor doc,Patient pat) - Displays appointments associated with healthcard number of patient

Justification:
The booking class is essentially the receptionist. There needs to be a class with all of the tools needed for
the user to interact with the system. This class allows the user to create their patient profile,
appointment, and check their existing appointments.

Class: Main
Attributes: counter: integer, patients: Patient[], appointments: Appointment[]

Methods:
main(String[] args) - Launches the clinic system program

Justification: 
This class applies the classes built to model all of the entities in a working clinic system and ties 
together all of the logic by utilizing all of the methods available.
